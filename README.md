C-Paint

Uma recriação do aplicativo Microsoft Paint, desenvolvida em C# com fins educacionais.

Sobre

O C-Paint foi desenvolvido com o objetivo de recriar algumas das principais funcionalidades
do famoso aplicativo Microsoft Paint, utilizando C#, Windows Forms e recursos do .NET, como 
System.IO e System.Drawing.

O projeto foi desenvolvido como uma forma de praticar conceitos de programação, desenvolvimento
de interfaces gráficas e manipulação de arquivos e imagens.

Tecnologias utilizadas
C#
.NET
Windows Forms
Visual Studio
System.IO
System.Drawing

Como executar o projeto:
Baixe ou clone este repositório.
Abra o arquivo C-Paint.sln no Visual Studio.
Aguarde o Visual Studio carregar o projeto e suas dependências.
Pressione F5 ou clique em Iniciar.
O projeto será compilado e o programa será executado.
Armazenamento de dados

O programa utiliza um arquivo Data.dat para armazenar determinados dados durante sua utilização.

Esse arquivo não está incluído no repositório, pois é gerado e armazenado localmente pelo programa quando necessário.
